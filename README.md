# Music_database_SQL_Project
📌 Objective

The purpose of this project is to analyze a music playlist database using SQL. By writing and executing SQL queries, we aim to extract meaningful insights that will help the music store:

- Understand its business performance and growth trends
- Explore customer behavior and preferences
- Answer key business-related questions through data analysis

🚀 Key Highlights
- SQL-based analysis of the music playlist database
- Queries designed to provide business insights
- Focus on data-driven decision-making
